# UI素材の仕様と生成指示

RPG MOD の画面（ステータス・ロール選択・チーム・HP表示）を Minecraft らしく整えるための素材の仕様。
画像生成は、この表の「生成指示」をそのまま使い、指定の大きさとファイル名で保存する。

## 共通ルール

- 作風: Minecraft のバニラ UI に近いピクセルアート。角は直線的に、影は1段階だけ暗く。
- 色: 背景は暗い石・木目系（#2b2b2b〜#4a4a4a）、枠は金（#c9a227）。文字色は画像に含めない。
- 文字（ロール名・ステータス名など）は画像に入れない。ゲーム側で翻訳して描く。
- 保存形式: PNG（透過あり）。ファイルは `src/main/resources/assets/rpgmod/textures/gui/` に置く。
- 9分割（nine-slice）で伸ばす素材は、四隅の枠の太さを 4px にそろえる。

## 5. 画面の見た目のガイド

- **ロール選択画面**: 6つのロールを2列×3行で並べ、アイコンとボタンを組み合わせる。選択中のロールは金色の枠。
- **ステータス画面**: 各行に「アイコン・名前・値・＋ボタン」。残りポイントは大きく、金色の文字で上に表示。
- **チーム画面**: 上にチーム名、中央にメンバー一覧（リーダーに王冠のアイコン）、下に招待欄。
- **HP 表示**: 画面下中央に HP バー。数字は横棒の上に小さく。

## 生成したあとの作業

1. 画像を上の表のファイル名で保存し、`src/main/resources/assets/rpgmod/textures/gui/` に入れる。
2. 作ってくれた画像を渡してもらえれば、画面の描画コードを差し替える。
3. ゲームで見た目を確認し、大きさや色を調整する。
