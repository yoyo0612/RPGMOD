# RPG MOD 要素定義

対象: Minecraft 1.21.1 / NeoForge

このドキュメントは RPG MOD の要素の仕様を定義する。数値はすべて仮の値で、実装しながら調整する。

---

## 1. レベル・経験値

プレイヤーはモンスターを倒すことで経験値を得て、レベルが上がる。

| 項目 | 仕様 |
|---|---|
| 最大レベル | 50 |
| 経験値の獲得 | モンスター撃破時に、モンスターごとに決められた量を得る |
| 必要経験値 | `100 × 現在のレベル`（次のレベルまでに必要な量） |
| レベルアップ時 | ステータスポイントを 3 獲得する（ステータスに振り分ける） |

- 経験値とレベルは、プレイヤーの永続データとして保存する。
- 死亡時のペナルティは**あり**。内容は検討中（下記「未決定の事項」）。

## 2. ステータス

プレイヤーの戦闘能力を表す値。レベルアップで得たポイントを振り分けて強化する。

| ステータス | 役割 | 1ポイントあたり |
|---|---|---|
| HP（体力） | 最大体力 | +2 |
| ATK（攻撃力） | 与えるダメージを増やす | +1 |
| DEF（防御力） | 受けるダメージを減らす | +1 |
| MAG（魔力） | 魔法のダメージ・回復量を増やす | +1 |
| MP（魔力量） | 魔法を使うための資源の最大値 | +5 |

- 初期値は全員共通（HP 20 / MP 20 / ATK 0 / DEF 0 / MAG 0）。ロールと出身によるボーナスは section 4・5 で決める。
- 振り分けは「ステータス画面（キー入力で開く）」から行う。
- **振り分けたポイントは後から変更できない。**

## 3. 武器

武器は「ランク」と「種類」で分類する。今回の範囲に防具は含めない。

### ランク

| ランク | 色 | 攻撃力の補正 |
|---|---|---|
| Common | 白 | +0 |
| Rare | 青 | +2 |
| Epic | 紫 | +4 |
| Legendary | 金 | +6 |

### 武器の種類

| 種類 | 例 | 特徴 | 使えるロール |
|---|---|---|---|
| 剣 | 勇者の剣（仮称） | 近接攻撃。バランス型。 | ファイター |
| 大斧 | 鉄の大斧（仮称） | 攻撃は遅いが重い。 | タンク |
| 短剣 | 影の短剣（仮称） | 攻撃間隔が短い。急所攻撃に向く。 | アサシン |
| 杖 | 魔法の杖（仮称） | 魔法の威力を上げる。 | メイジ、サポート |
| 弓 | 狩人の弓（仮称） | 遠距離攻撃。矢を飛ばす。 | マークスマン |

- 武器には**必要レベル**があり、レベルが足りないと装備できない。
- 武器のダメージは「武器の基本攻撃力 + ATK + ランク補正」で計算する。
- 使える武器は、選んでいるロールの武器の和集合とする（2ロールなら両方の武器が使える）。
- 弓の矢は、今は無限に使えるものとする（仮。消費型にするかは未定）。

## 4. ロール

プレイヤーは **ロールをちょうど2つ** 選ぶ。ロールは LoL の6つのロール（戦闘スタイルの分類）をもとにしている。レーン（配置場所）ではない。

- **選ぶタイミング**: ゲームに最初に入ったとき。
- **重複不可**: 同じロールを2つ選ぶことはできない。
- 選び直しはできない。

### ロール一覧

| ロール | 役割 | 使える武器 | 初期ボーナス（仮） |
|---|---|---|---|
| ファイター | 近接で戦う攻撃型 | 剣 | ATK +3、HP +6 |
| タンク | 硬くて味方を守る前衛 | 大斧 | HP +10、DEF +3 |
| メイジ | 攻撃魔法で火力を出す | 杖 | MAG +3、MP +10 |
| アサシン | 機動力で急所を狙う | 短剣 | ATK +4、HP +4 |
| マークスマン | 遠距離から攻撃を続ける | 弓 | ATK +3、HP +4 |
| サポート | 回復と味方の強化 | 杖 | MP +10、MAG +2、HP +6 |

### 2ロールを選んだときのルール

- 初期ボーナスは選んだ2ロールの**合計**になる。
- 使える武器は、2ロールの和集合になる。
- 例: ファイター + メイジ → 剣・杖が使える。

※スキルは今回は検討対象外（section 7 の保留案を参照）。

## 5. 出身とチーム

プレイヤーは、ロールと同じタイミング（ゲームに最初に入ったとき）に **出身** を1つ選ぶ。出身は所属チームになる。

### 出身の内容

| 出身（仮称） | 得意属性 | 出身ボーナス（仮） |
|---|---|---|
| 王国 | 火 | HP +5 |
| 海洋国 | 水 | MP +10 |
| 空の民 | 風 | ATK +2 |
| 山岳の民 | 土 | DEF +2 |

### 得意属性

- 得意属性は、出身ごとに1つ決まる（火・水・風・土）。
- 得意属性を持つ攻撃は、ダメージが **+10%** される（仮）。
- 属性どうしの相性（有利・不利）は今回は決めない。

### チームのルール

- 同じ出身のプレイヤーは、同じチーム（味方）になる。
- 出身は、選んだら変更できない。
- 出身の数や名前は仮。

### 出身とロールの組み合わせ

- 出身とロールは別々に選ぶ。同じ出身でも、ロールは自由に組める。
- 出身ボーナスと、ロールのボーナスは合計される。

---

## 要素どうしの関係

- 倒した敵 → 経験値 → レベルアップ → ステータスポイント → ステータス（HP・ATK・DEF・MAG・MP）
- ロール（2つ） → 使える武器、初期ボーナス
- 出身 → チーム、得意属性、出身ボーナス
- 武器（必要レベル・ランク） → 攻撃力 → 戦闘

## 6. 未決定の事項

以下はまだ決めていない。決まったら本ドキュメントを更新する。

1. **死亡時のペナルティの内容**: ペナルティは入れる方針。候補は次のとおり。
   - A. 現在の経験値の一部を失う（例: 10%）
   - B. 装備中の武器をドロップする
   - C. 一定時間、ステータスが下がる状態になる
2. **出身の内容**: 出身の名前・数・得意属性の割り当ては仮。ボーナスも仮。
3. **チームの敵対関係**: 出身が違うプレイヤー同士は敵になるか、中立か。
4. **属性の相性**: 火・水・風・土の有利・不利を入れるか。
5. **弓の矢**: 無限にするか、消費型にするか。

決定済みの事項（参考）: ロール制（LoLの6ロールからちょうど2つ、重複不可、ゲーム初回に選択）／ロールの選び直しは不可／出身（チーム）の追加（ゲーム初回に選択、変更不可）／ステータス振り分けは変更不可／防具は今回の範囲に含めない／スキルは今回は検討しない。
対象バージョンは Minecraft 1.21.1 / NeoForge のまま（変更の指示なし）。
