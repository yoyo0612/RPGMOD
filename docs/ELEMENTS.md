# RPG MOD 要素定義（ドラフト）

対象: Minecraft 1.21.1 / NeoForge

このドキュメントは RPG MOD の要素の仕様を定義する。数値はすべて仮の値で、実装しながら調整する。

---

## 1. レベル・経験値

プレイヤーはモンスターを倒すことで経験値を得て、レベルが上がる。

| 項目 | 仕様 |
|---|---|
| 最大レベル | 50 |
| 経験値の獲得 | モンスター撃破時に、モンスターごとに決められた量を得る |
| 必要経験値 | `100 × 現在のレベル`（次のレベルまでに必要な量） |
| レベルアップ時 | ステータスポイントを 3 獲得する（ステータスに振り分ける） |

- 経験値とレベルは、プレイヤーの永続データとして保存する。
- 死亡してもレベルと経験値は失われない（ペナルティなし）。※未決定（下記参照）

## 2. ステータス

プレイヤーの戦闘能力を表す値。レベルアップで得たポイントを振り分けて強化する。

| ステータス | 役割 | 初期値 | 1ポイントあたり |
|---|---|---|---|
| HP（体力） | 最大体力 | 20 | +2 |
| ATK（攻撃力） | 与えるダメージを増やす | 0 | +1 |
| DEF（防御力） | 受けるダメージを減らす | 0 | +1 |
| MAG（魔力） | 魔法のダメージ・回復量を増やす | 0 | +1 |
| MP（魔力量） | 魔法を使うための資源の最大値 | 20 | +5 |

- 振り分けは「ステータス画面（キー入力で開く）」から行う。
- 振り分けたポイントは後から変更できない（※未決定、下記参照）。

## 3. 装備・武器

武器と防具は「ランク」と「種類」で分類する。

### ランク

| ランク | 色 | 攻撃力・防御力の補正 |
|---|---|---|
| Common | 白 | +0 |
| Rare | 青 | +2 |
| Epic | 紫 | +4 |
| Legendary | 金 | +6 |

### 武器の種類

| 種類 | 例 | 特徴 |
|---|---|---|
| 剣 | 勇者の剣（仮称） | 近接攻撃。攻撃力が高い。 |
| 杖 | 魔法の杖（仮称） | 魔法の威力を上げる。ATKは低い。 |

- 武器には**必要レベル**があり、レベルが足りないと装備できない。
- 武器のダメージは「武器の基本攻撃力 + ATK + ランク補正」で計算する。
- 防具は今回の範囲に含めない（次のフェーズで検討）。

## 4. スキル・魔法

MPを消費して発動する能力。スキルはスロットに登録し、キーで発動する。

| 項目 | 仕様 |
|---|---|
| 発動条件 | 装備中の武器・必要レベル・MPが足りていること |
| コスト | MP を消費 |
| クールダウン | 発動後、一定時間は再発動できない |
| スロット | 4 つ（キー 1〜4 で発動） |

### 仮のスキル一覧

| 名前 | 種別 | MP消費 | CT | 効果（仮） |
|---|---|---|---|---|
| ヒール | 魔法 | 5 | 5 秒 | MAG に応じて HP を回復 |
| ファイアボール | 魔法 | 8 | 3 秒 | 前方に火球を飛ばし、MAG に応じたダメージ |
| 斬撃 | 剣スキル | 4 | 4 秒 | 剣で前方を攻撃し、ATK に応じたダメージ |

---

## 要素どうしの関係

- 倒した敵 → 経験値 → レベルアップ → ステータスポイント → ステータス（HP・ATK・DEF・MAG・MP）
- 武器（必要レベル・ランク） → 攻撃力 → 戦闘
- レベル・武器 → 使えるスキル → MP を消費して発動

3. **ステータス振り分けの取り消し**: 一度振ったポイントを後から変更できるようにするか。
4. **防具の扱い**: 今回の範囲から外してよいか。
5. **対象バージョン**: 現在は Minecraft 1.21.1 / NeoForge。変更が必要か。
